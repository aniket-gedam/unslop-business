# Visual quality checklist

Use this before calling a business website complete.

## Brand and art direction
- [ ] The design feels specific to this business.
- [ ] The page has a recognizable visual point of view.
- [ ] Reference inspiration has been transformed into an original design.
- [ ] Photography and graphics support the brand.

## Hierarchy and layout
- [ ] The first viewport explains what the business offers.
- [ ] The primary CTA is easy to find.
- [ ] Sections have a clear reason to exist.
- [ ] Spacing, alignment, and content widths are consistent.
- [ ] No accidental repetition of generic card grids.

## Content
- [ ] Copy is specific and useful.
- [ ] No placeholder text remains.
- [ ] No facts, awards, reviews, or statistics were invented.
- [ ] Product/service details are accurate to supplied information.

## Functionality
- [ ] Navigation works.
- [ ] Links and CTAs have meaningful destinations.
- [ ] Forms validate and provide clear feedback.
- [ ] Commerce/booking features are real or clearly marked as integration-required.
- [ ] Keyboard and focus behavior work.

## Responsive
- [ ] Desktop checked.
- [ ] Tablet checked.
- [ ] Mobile checked.
- [ ] No horizontal overflow.
- [ ] Images crop appropriately.
- [ ] Navigation and tap targets work on touch devices.

## Engineering
- [ ] Existing project conventions are respected.
- [ ] Components are reusable where useful.
- [ ] Images are optimized and lazy-loaded when appropriate.
- [ ] Semantic HTML and labels are present.
- [ ] Reduced-motion preferences are respected.
- [ ] Build/runtime errors checked where possible.

## Honesty
- [ ] Only tests actually performed are reported.
- [ ] Any unavailable visual inspection is disclosed.
- [ ] Remaining limitations are listed clearly.
