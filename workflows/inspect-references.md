# Workflow: inspect references

1. Collect all reference URLs from the user.
2. Open each URL with the available browser tool.
3. Inspect relevant pages, not only the homepage, when the business journey requires it.
4. Capture screenshots at desktop and mobile sizes when possible.
5. Inspect interactions: menus, hover/focus, navigation, filters, forms, cart/booking, and footer.
6. Complete `references/reference-analysis.md` for each reference.
7. Separate:
   - Observed facts.
   - Interpretations.
   - Unverified assumptions.
8. Summarize the transferable principles across references.
9. Identify conflicting patterns and choose only those appropriate to the user's business.
10. If a URL is inaccessible, report that and continue with the remaining references. Never invent observations.

Output a concise reference synthesis before implementation:
- Design mood.
- Typography direction.
- Layout and imagery principles.
- Useful UX patterns.
- What to avoid.
- Original design direction for this business.
