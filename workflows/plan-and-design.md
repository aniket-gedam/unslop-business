# Workflow: plan and design

1. Review the user's brief and existing project.
2. Define the target audience, offer, and primary conversion.
3. Create a one-paragraph creative direction.
4. Map the page architecture to the business model.
5. Define design tokens for color, type, spacing, grid, media, and motion.
6. Plan responsive behavior for navigation, hero, grids, forms, and footer.
7. Identify required assets and missing content.
8. Confirm any critical assumptions with the user; otherwise proceed with clearly stated assumptions.
9. Build the smallest coherent design system that can support the requested pages.

Before coding, be able to answer:
- What makes this business different?
- What should a visitor understand in five seconds?
- What should the visitor do next?
- Why does this visual direction fit this audience?
- Which reference principles influenced the design, and how have they been made original?
